Plan: add en↔sw, en↔tl (later en↔ur) to the slimt/bergamot catalog by distilling OPUS-MT teachers into tiny SSRU students. slimt's decoder is **SSRU-only** (Modules.hh `DecoderLayer` = cross-attn + SSRU, no self-attention; default decoder_layers=2), so it cannot run full OPUS-MT/CTranslate2 models directly — the only in-format path is distillation to a 6-2 tiny student, then int8 quantize + lexical shortlist. Argos models are CTranslate2 (wrong runtime) and there's no CT2→Marian converter, so Argos itself is a dead end.

Pipeline scripts live in `~/git/translator-rs/scripts/opus-trainer/` (venv + requirements.txt). `validate_teacher.py` is the free CPU gate (FLORES-200 devtest via the NLLB tarball, chrF++/BLEU through transformers MarianMTModel).
